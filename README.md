# Film4k TV Playlist

Playlist TV tự động cập nhật từ film4k.net (203 kênh).

- **film4k_tv.m3u** — playlist cho VLC / PotPlayer / TiviMate...
- **film4k_tv.json** — dữ liệu đầy đủ (tên, logo, nguồn, link)

Link raw (dùng cho app IPTV):
`https://raw.githubusercontent.com/Gicnycjgfg/film4k-tv/main/film4k_tv.m3u`

Lưu ý: token kênh TV360 hết hạn sau ~5-6 tiếng. Playlist được làm mới tự động mỗi 4 giờ.
